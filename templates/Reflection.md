Module 4 Assignment 1 – Reflection
For this assignment, I created a RESTful application using Python, Flask, and JavaScript to retrieve vehicle information from a public API. I started by creating a Flask application that sends a GET request to the NHTSA API and processes the JSON response. I then modified the code to filter the results so that only items in the "Active Safety System" group would be displayed.
After testing the API, I created an HTML page that uses asynchronous Fetch to retrieve the filtered data and display it in a table. I also included loading and error messages to help users understand what is happening when the application requests information.
What surprised me most was how the application could retrieve information from an external source without storing the data locally. Seeing the 11 matching safety systems appear in the table helped me understand how the different components work together. This assignment improved my understanding of JSON filtering, HTTP GET requests, asynchronous Fetch, and communication between systems. I would like to learn more about working with larger APIs and handling different types of responses.
